# Security Policy

## Supported Versions

Currently, the `main` branch is the only supported version.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please do NOT report it by creating a public issue.

Instead, please send an email to the repository owners.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If you have not received a reply to your email within 48 hours, or have not heard from us for a few days, please contact us again to ensure we received your original message.
